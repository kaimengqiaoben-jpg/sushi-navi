## 給与交渉は「いつ・どう言うか」で全て決まる

「給料を上げてほしいけど言い出せない」——飲食業界でよく聞く悩みです。
給与交渉は空気を読むのではなく、**正しいタイミングと言い方の技術**です。

## 昇給交渉のベストタイミング3つ

### ① 入社1年後の評価面談
最も自然なタイミング。「1年間の振り返りとして」という文脈で話しやすい。

### ② 繁忙期を乗り越えた直後
「正月・お盆・年末を乗り切った」という実績が交渉の根拠になる。

### ③ 褒められた・感謝された直後
良い評価をもらったタイミングに「このような評価をいただき、今後も貢献していきたいと思っています。給与についても一度ご相談させていただけますか？」と続ける。

## 給与交渉の言い方テンプレート

### 基本形（シンプル版）

```
「〇〇さん（オーナー/大将）、少しお時間をいただけますでしょうか。
入社してから〇ヶ月が経ち、〔担当業務・実績〕もできるようになりました。
つきましては、給与について一度ご相談させていただけますでしょうか。
現在月〇〇万円をいただいていますが、
〔具体的な理由：生活費/スクールローン返済など〕もあり、
可能であれば月〇〇万円を目標にしていただけますと大変助かります。」
```

### 実績ベース版（説得力が高い）

```
「この〇ヶ月で〔握りの担当が増えた/仕込みを一人でできるようになった/
お客様から指名をいただいた〕など、できることが増えてきました。
貢献度に見合った評価をいただきたく、
給与の見直しをご検討いただけますでしょうか。」
```

### 転職を匂わせる版（最終手段）

```
「貴店で長く働きたいと思っているのですが、
現在の給与水準では生活が厳しく、
他の求人も検討せざるを得ない状況になっています。
ぜひご相談の機会をいただけますでしょうか。」
```

→ これは本当に転職を考えている場合のみ使う。嘘をつくと信頼を失う。

---

## 断られた時の対処法

### パターン①「今は難しい」と言われた

```
「わかりました。では〇ヶ月後に改めてご相談させてください。
それまでに〔具体的な目標〕を達成できるよう頑張ります。
目標の確認をさせていただけますか？」
```

→ 期限と目標を設定する。曖昧なまま終わらせない。

### パターン②「規定があって変えられない」と言われた

給与ではなく別の交渉に切り替える。

```
「給与以外の面で、交通費の支給や食事補助など、
待遇面での改善は可能でしょうか？」
```

### パターン③ 半年待っても変化がない場合

転職を本格検討するタイミング。クックビズ・飲食店.comに登録して市場価値を確認する。

## 給与以外で交渉できるもの

| 交渉項目 | 効果 |
|---------|------|
| 交通費全額支給 | 月1〜3万円相当 |
| まかない（食事補助） | 月2〜3万円相当 |
| 住宅補助 | 月3〜5万円相当 |
| 休日を週2に増やす | 生活品質向上 |
| 研修費用の会社負担 | スキルアップ支援 |

給与が上がらない場合でも、これらを組み合わせると実質的な手取りが増えます。
