## 「こんなはずじゃなかった」を防ぐために

転職して3ヶ月で辞めた人の多くが「求人票を見ただけで入った」と言います。
寿司業界にはブラックな職場が一定数存在します。

事前に見抜けば回避できます。このチェックリストを面接・見学前に使ってください。

---

## 求人票で見るべき20項目

### ✅ 給与・待遇（10点）

- [ ] **月給の下限が明記されている**（「月給15万円〜」など具体的な数字）
- [ ] **試用期間中の給与が本採用と同額またはほぼ同額**
- [ ] **残業代の計算方法が書いてある**（「固定残業代〇時間分含む」は注意）
- [ ] **社会保険（健康・厚生年金・雇用・労災）の全4種類加入**
- [ ] **有給休暇の付与が明記されている**
- [ ] **昇給の仕組みが書いてある**（「年1回昇給あり」など）
- [ ] **休日が週2日以上**（飲食業でも週2は最低ライン）
- [ ] **定休日がある**（週7営業で休みゼロはNG）
- [ ] **深夜手当が支払われる**（22時以降は25%増が法律上の義務）
- [ ] **試用期間が3ヶ月以内**（6ヶ月以上は要注意）

---

### ✅ 仕事内容・職場環境（10点）

- [ ] **仕事内容が具体的に書いてある**（「その他雑務」だけは危険）
- [ ] **「アットホームな職場」という表現がない**（主観的すぎて意味なし）
- [ ] **「やる気さえあれば」という表現がない**（労務管理が甘い可能性）
- [ ] **スタッフ数・在籍年数の記載がある**（離職率の高い店は書けない）
- [ ] **研修制度・OJTの説明がある**
- [ ] **「即戦力」という言葉が過度に使われていない**（未経験を育てる気がない可能性）
- [ ] **求人掲載期間が異常に長くない**（何ヶ月も掲載中は人が定着していない可能性）
- [ ] **口コミサイトに著しく悪い評価がない**（食べログ・Googleレビュー等）
- [ ] **InstagramやSNSで実際のスタッフの様子が見える**
- [ ] **見学・体験を快く受け入れてくれる**

## 面接・見学で直接確認すること

### 必ず聞く5つの質問

**① 「現在のスタッフの平均在籍年数はどれくらいですか？」**
→ 1〜2年以下が多い場合、定着しにくい環境の可能性あり。

**② 「前任の方はなぜ辞めたのですか？」**
→ 「一身上の都合」以外の理由が出てくる場合は要注意。

**③ 「繁忙期はどれくらい忙しくなりますか？休みは変わりますか？」**
→ 「正月は休みなし」「GWは連続勤務」が当然の文化かどうか確認。

**④ 「残業代は別途支払われますか？」**
→ 曖昧な答えや「うちはそういう文化じゃない」は危険サイン。

**⑤ 「先輩スタッフと話す機会をいただけますか？」**
→ 断られる場合は隠したいことがある可能性。

---

## 即撤退すべきレッドフラッグ5つ

1. **面接その日に即決を迫られる**
2. **「給料は後で説明する」と言って最後まで教えない**
3. **面接中に大将・先輩が怒鳴っている声が聞こえる**
4. **清掃が行き届いていない（冷蔵庫の扉、床、ケース内）**
5. **口頭での約束が多く、書面（労働条件通知書）を出したがらない**

---

## 入社前に必ず受け取るもの

法律上、採用時に書面交付が義務付けられています。

- **労働条件通知書**（給与・労働時間・休日が明記）
- **雇用契約書**（双方署名）

これを「入社してから渡す」と言う職場は法律違反です。転職を再考してください。
