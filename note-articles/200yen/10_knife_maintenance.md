## 包丁の切れ味が料理の質を決める

## 毎日の手入れ（使用後5分）

### 手順

1. **流水でしっかり洗う**
   - 洗剤は少量でOK。食材の酸（酢・柑橘）が刃を傷める
   - スポンジで優しく。金属タワシはNG

2. **完全に水気を拭き取る**
   - 刃部分は布巾を折り畳んで「刃の背から刃先に向けて」拭く
   - 柄の中に水が入ると腐食の原因になる

3. **椿油（または刃物用オイル）を薄く塗る**
   - 1〜2滴を布になじませて刃面全体に薄く伸ばす
   - 錆び防止に必須

4. **鞘に収めるか布巻きで保管**
   - 他の道具と金属接触させない
   - 引き出しの中でごちゃごちゃ保管はNG（刃欠けの原因）

## 週1の本砥ぎ

### 砥石の選び方

| 砥石 | 番号目安 | 使い方 |
|------|---------|--------|
| 荒砥 | #120〜#400 | 大きな欠け・刃の形成に使う。通常は不要 |
| 中砥 | **#1000** | メインの砥石。これ1枚で8割対応 |
| 仕上げ砥 | #3000〜#6000 | 刃先を磨く・刃の鋭さを出す |
| 超仕上げ | #8000〜 | プロ用。なくてもよい |

**→ まずは#1000と#3000の2枚を揃えれば十分。**

### 砥ぎの基本姿勢

```
① 砥石を水に10〜15分浸す（砥石が水を吸うまで）
② 台の上に砥石を安定させる（ゴム台または濡れ布巾の上）
③ 利き手で柄を持ち、もう一方の指を刃面に添える
④ 刃の角度：約15〜20度（10円玉2枚分が目安）
⑤ 前後に動かす（引く時に力を入れる）
```

### 角度の覚え方

親指の厚み（約1.5cm）を砥石と刃の間に入れたくらいの角度が15〜20度の目安です。

---

## 砥ぎ手順（柳刃包丁）

### 1. 裏面から始める

柳刃は片刃（表だけに刃がついている）なので、裏面は砥石にぴったり当てて「バリ（かえり）」を取るだけでOK。

```
裏面：砥石に平行に当てて、軽く5〜10回引く
```

### 2. 表面を砥ぐ

```
① 刃元（柄に近い部分）から砥ぎ始める
② 刃の長さを3分割して、各部分を20〜30回砥ぐ
③ 全体を通して砥いで、最後に仕上げる
```

### 3. バリ（かえり）の確認と除去

砥いでいると刃先にバリ（返り）が出ます。指で軽く触ると引っかかる感触がバリです。

```
① バリが出たら裏面を砥石に当てて軽く5回引く
② 新聞紙を立てて刃を引いて切り落とす
③ 腕の毛を当てて剃れるくらいが合格ライン
```

## 包丁の錆び対処法

### 小さな錆び（点錆）

砥石で砥ぐ前に「錆び取り消しゴム（砥石メーカーが販売）」で擦る。500円程度で購入可能。

### 広範囲の錆び

専門の職人に預けるか、荒砥（#400）から砥ぎ直す。

### 錆びない保管方法

- 使用後は必ず乾拭き＋椿油
- ステンレスより**鋼（はがね）の包丁**の方が錆びやすいが切れ味が良い
- 冬場は特に注意（結露で錆びやすい）
