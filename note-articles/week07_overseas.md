# 【Week7】海外で寿司職人として働く方法【ビザ・求人・年収】

---ここから先は月額980円で読めます---

日本で月20万円の収入が、アメリカでは月50〜80万円になることがあります。
「英語ができないから無理」と思っている人が多いですが、寿司職人の技術があれば英語力はハードルではありません。

今回は、実際に海外就職した寿司職人のケースを元に、現実的なルートを解説します。

## 料理人向け就労ビザの種類

### アメリカの場合

**O-1ビザ（卓越した能力）**
- 日本で有名な料理人向け
- 難易度：高

**H-2Bビザ（一時就労）**
- 雇用主側のスポンサーが必要
- 1〜3年の就労が可能

**L-1ビザ（企業内転勤）**
- 日系レストランチェーンの海外転勤に使われる
- 日本国内の会社で1年以上勤務が条件

### カナダの場合

**LMIA（Labour Market Impact Assessment）ビザ**
- カナダの雇用主が取得するビザ
- 「カナダ人に代わる人材がいない」を証明する必要あり
- 寿司職人は需要が高くLMIAが取りやすい

**ワーキングホリデー（30歳以下）**
- 1年間の就労可能
- 試しに海外を経験するのに最適

### オーストラリアの場合

**ワーキングホリデー（31歳以下）**
- 1年間の就労可能。人気の選択肢

**スキルドビザ（Subclass 482）**
- 料理人・シェフはスキル不足職種に指定されており取りやすい
- 雇用主のスポンサー必要

## 英語ゼロから海外就職した実例

### Aさん（33歳・元会社員）

- スクールで寿司の技術習得（3ヶ月）
- 日本の日系寿司チェーンに就職（1年間）
- 会社のL-1ビザでニューヨーク支店へ転勤
- 現在：年収900万円相当（チップ込み）

**英語力：「Hello」「Thank you」程度からスタート。厨房ではほぼ日本語OK**

### Bさん（28歳・元料理人）

- 寿司アカデミーで英語対応コース受講（3ヶ月）
- 卒業後、スクールの海外就職プログラムでシンガポールへ
- 現在：月収65万円（日本時代の3倍）

## 現地生活コストと手取り計算例（ドバイ）

| 項目 | 月額 |
|------|------|
| 家賃（1LDK） | 12〜18万円 |
| 食費 | 5〜8万円 |
| 交通費 | 2〜3万円 |
| **合計生活費** | **約20〜30万円** |
| **月収** | **70〜100万円** |
| **実質手取り（税引き後）** | **40〜70万円** |

日本で手取り20万円の仕事をしている人が、ドバイで40〜70万円の手取りを得られる計算になります。
