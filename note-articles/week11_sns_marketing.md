# 【Week11】寿司職人がSNSで集客する方法【Instagram・TikTok・YouTube】

---ここから先は月額980円で読めます---

「料理の腕はあるけど、集客の仕方がわからない」
独立・副業で一番つまずくのがここです。

でも実は、寿司職人のコンテンツはSNSで最もバズりやすいジャンルのひとつです。
魚をさばく手元、シャリを握る動作、完成した一貫の美しさ——見ている人が思わず止まる映像素材の宝庫です。

---

## 料理人が使うべきSNSの優先順位

| SNS | 向いていること | 最初に注力すべきか |
|-----|---------------|------------------|
| **Instagram** | 写真・リール・ストーリーで地元集客 | ✅ 最優先 |
| **TikTok** | 動画バイラルで認知拡大 | ✅ 2番目 |
| YouTube | 長尺動画・料理解説 | 後回しでOK |
| X（Twitter） | 飲食業では効果薄い | 不要 |

最初はInstagramだけに集中して、慣れてきたらTikTokも始める戦略が正解です。

---

## Instagramで予約につながるプロフィール設計

### プロフィール欄に入れる必須要素

```
🍣 [名前] | 出張寿司職人
📍 [活動エリア]（例：東京都内・神奈川対応）
✅ スクール修了・食品衛生責任者
📩 ご予約はプロフィールリンクから
👇 予約ページ or LINE公式アカウント
```

### プロフィール写真

- 白衣を着て、寿司を持っている写真が最強
- 笑顔で親しみやすい表情を

### フィードの統一感

同じ色味・雰囲気で揃えると一目でプロと分かる。
「木の板の上にのった寿司」を統一ビジュアルにするだけでOK。

---

## バズる寿司コンテンツの作り方

### 伸びる投稿パターン（実績あり）

**① 手元動画（リール・TikTok）**
「マグロの柵を引く手元」「シャリを10貫連続で握る」
→ 無言でもBGMだけで成立する。スマホを三脚で固定して撮るだけ

**② 「知らなかった」系情報**
「回転寿司のシャリと高級寿司のシャリの違い」
「スーパーのサーモンと築地のサーモンの見分け方」
→ 文字テロップ＋手元映像で完成

**③ 仕込みの様子**
「今日の仕入れ（市場・魚屋）」「仕込みの一日」
→ 料理人のリアルに共感が集まる

**④ Before/After**
「仕込み前の魚→捌いた後の状態→完成した寿司」
→ 変化が見えるコンテンツはシェアされやすい

## TikTokで職人の手技を見せる動画の撮り方

### 機材は最小限でOK

- スマートフォン（最新機種推奨）
- 100均の三脚（卓上タイプ）
- 照明：リングライト（3,000〜5,000円）
- BGM：TikTok内の人気音楽を使う

### 撮影の基本

- **俯瞰（真上から）撮影**：まな板での作業はこれが一番映える
- **横からのアングル**：握る動作・盛り付けはこちら
- 動画の長さ：15〜30秒が最もバズりやすい

### キャプション（説明文）の書き方

```
◯◯を使ったマグロの引き方 🔪
—-
📍出張寿司のご予約受付中
詳しくはプロフリンクから

#出張寿司 #寿司職人 #sushi #和食 #日本料理
```

## DM→予約→リピートの導線設計

### ステップ①：DMへの誘導

投稿に「ご予約・お問い合わせはDMまたはプロフリンクから」と必ず記載。

### ステップ②：DM返信テンプレート

```
ご連絡ありがとうございます！
出張寿司のご予約についてご案内します。

【基本情報】
・お日にち：
・人数：
・場所（お住まいの地域）：
・ご予算の目安：

以上をDMでお知らせいただければ、
詳細なお見積もりをお送りします。
```

### ステップ③：リピートを生む工夫

- 当日「インスタに投稿してくれたら次回10%オフ」とお客様にお願いする
- 終了後にDMで「また機会があればぜひ」とフォローメッセージを送る
- LINE公式アカウントを作って誕生日クーポンを送る
