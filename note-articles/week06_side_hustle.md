---ここから先は月額980円で読めます---

出張寿司は今、最も参入しやすい料理人副業のひとつです。
店舗不要・初期費用30〜50万円・週末2〜3件で月10万円の収益が狙えます。

「本当にそんなに稼げるの？」と思うかもしれませんが、実際にIT企業を辞めて出張寿司に転身した人が何人もいます。その立ち上げ方を全部話します。

## 出張寿司ビジネスの仕組み

### 市場規模・需要

- 手巻き寿司パーティー・誕生日会・結婚記念日
- 法人向け：接待・会社の懇親会
- 外国人向け：インバウンド体験（Airbnb体験で高単価）
- SNSで拡散されやすい「映える」体験コンテンツ

### 収益モデル

| サービス | 単価 | 月4回の場合 |
|---------|------|-------------|
| 家庭向け（4〜6名） | 2〜3万円 | 8〜12万円 |
| 法人・接待（10名〜） | 5〜10万円 | 20〜40万円 |
| Airbnb体験（2〜4名） | 1〜2万円/人 | 4〜8万円 |

週末2件こなすだけで月10万円は十分可能な数字です。

## 最初の集客方法

### ① ジモティー・タイムズ（即効性あり）

地元のジモティーに「出張寿司承ります」と投稿するだけで問い合わせが来ます。
最初の実績作りに最適。単価は低めでも口コミ・写真素材が得られます。

**投稿文テンプレート：**
```
【出張寿司】ご自宅・オフィスに職人が伺います
■内容：本格にぎり寿司（食材持参）
■対象：4名〜10名程度
■料金：お一人様3,500円〜（要相談）
■エリア：○○市・○○区周辺
【実績】スクール修了・食品衛生責任者取得済み
DM・LINE：@〇〇〇〇
```

### ② Instagram（中長期）

寿司を握る手元動画・仕込みの様子・完成した寿司の写真を毎日投稿。
3ヶ月で500〜1,000フォロワーが集まれば問い合わせが来始めます。

**最初に投稿すべき内容：**
1. 自己紹介（なぜ寿司職人を目指したか）
2. 道具紹介（包丁・道具の解説）
3. 仕込みの様子（映像）
4. 完成した寿司の写真

### ③ Airbnb体験（高単価・外国人向け）

Airbnb体験ページに「寿司握り体験」を出品。外国人観光客に1人5,000〜15,000円で体験を提供。英語が話せなくても翻訳アプリで対応できます。

## 料金設定の考え方

### 食材原価の目安

握り寿司（10貫）の食材費：800〜1,500円/人
（マグロ・サーモン・タコ・イカ・エビ等の相場から計算）

### 料金の計算式

```
料金 = 食材費 × 3〜4倍 + 交通費・出張費
```

**例：**
- 食材費：1,000円/人 × 5名 = 5,000円
- 料金：5,000円 × 3倍 = 15,000円 + 交通費2,000円 = **17,000円**
- 1時間〜1.5時間の作業で17,000円の売上

## 衛生管理・食中毒リスクの対策

副業でも食中毒が発生すると廃業・損害賠償のリスクがあります。

### 必ず取得すること

- **食品衛生責任者の資格**（1日講習・受講料6,000円程度）
- 都道府県によっては届出が必要な場合あり（保健所に確認）

### 衛生管理の基本

- 魚は当日仕入れ・当日使用が原則
- 保冷（10℃以下）を徹底
- 使い捨て手袋・アルコール消毒を徹底
- 当日体調不良の場合は必ずキャンセル（絶対に無理しない）
