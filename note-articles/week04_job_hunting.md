# 【Week4】寿司職人転職活動の進め方：履歴書・面接・給与交渉

---ここから先は月額980円で読めます---

スクールを卒業して、いざ転職活動。
でも「未経験なのにどう自分を売り込めばいいか分からない」という声をよく聞きます。

採用担当者が本当に見ているポイントは、技術力ではありません。
今回はその「採用の本音」と、内定をとるための具体的な準備を話します。

---

## 寿司店の求人票の読み方

求人票には書いていないことがたくさんあります。

### ブラック店の見分け方

**要注意のキーワード：**
- 「やる気さえあれば大丈夫」→ 労働環境・給与が整っていない可能性
- 「アットホームな職場」→ 個人的な裁量で労務管理している可能性
- 給与が「応相談」のみで下限が書いていない→ 低い可能性が高い
- 休日が「シフト制・週2日」だが具体的な日数がない

**良い求人のサイン：**
- 給与レンジが具体的（月22〜30万円）
- 研修期間・昇給の仕組みが書いてある
- 「スクール卒歓迎」「未経験可」の明記

### 確認すべき5項目

1. **試用期間の給与**（本採用より低い場合がある）
2. **残業の実態**（「残業なし」でも繁忙期は違う場合あり）
3. **社会保険の有無**（未加入の飲食店は少なくない）
4. **定休日の有無**（日曜定休か火曜定休かで生活が変わる）
5. **賄い・まかない制度**（食費が浮くかどうか）

## 履歴書・職務経歴書で評価されるポイント

### 未経験でも書けるアピールポイント

| 過去の経験 | 寿司店でのアピール方法 |
|-----------|----------------------|
| 接客・販売業 | 「お客様対応の経験があり、即戦力になれます」 |
| 営業 | 「数字への意識・目標達成への粘り強さがあります」 |
| 製造・工場 | 「手先の正確さ・衛生管理への意識があります」 |
| IT・デスクワーク | 「スクールで培った学習力・ITを使った業務改善ができます」 |

### 志望動機の書き方（テンプレート）

```
〇〇（前職の経験）で△△（気づき）を経験し、
人の喜びを直接感じられる仕事に就きたいと思いスクールで学びました。
貴店の〇〇（具体的な特徴）に魅力を感じ、
〇〇（自分の強み）を活かして貢献したいと思い応募しました。
```

## 面接でよく聞かれる質問と回答例

### Q：なぜ前職をやめて寿司職人を目指したのですか？

**悪い答え：**「前の会社が嫌になって…」（ネガティブ）

**良い答え：**「お客様の笑顔を直接見られる仕事をしたいと思い転職を決めました。スクールで学ぶうちに、料理の面白さと技術の奥深さにはまり、本気でプロを目指すことにしました。」

### Q：スクールで学んだことを教えてください

基礎技術（シャリ・さばき）＋衛生管理＋心構えの3点セットで答えると好印象。

### Q：厳しい環境でも続けられますか？

「続けられます」だけでは弱い。過去に苦しい状況を乗り越えたエピソードを添える。

### Q：給与はどれくらい希望しますか？

→ 後述の給与交渉の項目を参照。

## 給与交渉のタイミングと言い方

### タイミング

- 内定をもらった後（内定前は条件交渉しない）
- 「条件面で確認したいことがある」と前置きして聞く

### 言い方の例

「スクールの費用を一部ローンで賄っているため、可能であれば月〇〇万円以上でお願いできますでしょうか。もちろん仕事で成果を出してから昇給の相談もさせていただければと思います。」

### 相場感

| 業態 | 未経験入社1年目の目安 |
|------|----------------------|
| 回転寿司チェーン | 月22〜26万円 |
| 個人経営の寿司居酒屋 | 月20〜25万円 |
| 高級寿司店 | 月18〜22万円（修行期間） |
| ホテル・旅館 | 月22〜28万円 |

高級店は初年度の給与は低めですが、将来の年収は最も高くなりやすいです。
