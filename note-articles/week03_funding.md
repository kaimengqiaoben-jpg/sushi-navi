# 【Week3】スクール費用を最小化する給付金・ローン完全活用術

---ここから先は月額980円で読めます---

「スクールに行きたいけど、費用が高くて踏み出せない」

100万円近いスクール費用を見て、諦めた人は少なくないはずです。
でも実は、**正しく給付金を使えば実質30万円以下で通える**ことを知らない人がほとんどです。

今回は給付金の申請手順を、実際にハローワークに行く前日の準備から説明します。

---

## 専門実践教育訓練給付金とは

厚生労働省が指定したスクール・コースを修了すると、**受講費用の最大70%が戻ってくる制度**です。

| 項目 | 内容 |
|------|------|
| 補助率 | 受講費用の50%（就職後6ヶ月継続で追加20%、合計最大70%） |
| 上限額 | 年間56万円（3年間で最大168万円） |
| 対象者 | 雇用保険加入期間3年以上（初回は1年以上でOK） |
| 手続き先 | ハローワーク |

**例：100万円のスクール → 実質30万円で通える**

---

## ハローワーク訪問の手順

### 事前準備（前日までに）

- [ ] 雇用保険被保険者証（会社から受け取るもの）
- [ ] マイナンバーカードまたは運転免許証
- [ ] 通帳（給付金の振込先）
- [ ] 受講したいスクールのコース名・金額が書かれた資料

### ハローワークでの流れ

1. 窓口で「教育訓練給付金の相談をしたい」と伝える
2. 対象かどうか確認してもらう（5〜10分）
3. 対象スクールのリストをもらう
4. 行きたいスクールが対象かチェック

**ポイント：スクールに申し込む前にハローワークに行くこと。入学後では給付金が使えないケースがあります。**

---

## 一般教育訓練給付金（ハードルが低い）

専門実践よりも対象スクールが多い給付金です。

| 項目 | 内容 |
|------|------|
| 補助率 | 受講費用の20%（上限10万円） |
| 対象者 | 雇用保険加入期間1年以上（退職後1年以内も可） |
| 特徴 | 対象スクール数が多い。手続きが簡単 |

「専門実践の対象外だった」という場合も、こちらが使える場合があります。

---

## 給付金が使えない場合の資金調達

### 日本政策金融公庫の教育ローン

- 金利：年1.75〜2.0%（2024年時点）
- 上限：350万円
- 返済期間：最長15年

民間ローン（金利5〜15%）と比べて圧倒的に安い。**給付金と合わせて使うのが最強の組み合わせ。**

### 申請の流れ

1. 日本政策金融公庫のWebサイトで申し込み（オンライン可）
2. 審査（1〜2週間）
3. 通過後、スクール入学・受講開始
4. 受講修了後にハローワークで給付金申請
5. 給付金でローン繰り上げ返済

---

## シミュレーション：100万円スクールの場合

| フェーズ | 費用 |
|----------|------|
| スクール総額 | 1,000,000円 |
| 日本政策金融公庫ローン | 1,000,000円借入 |
| 受講修了後・給付金申請 | −500,000円（50%給付） |
| 就職6ヶ月継続後 | −200,000円（追加20%給付） |
| **実質自己負担** | **300,000円＋利息** |

月払いにすると月2〜3万円の返済。転職後の給与増加で十分カバーできます。
