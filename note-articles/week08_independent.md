## 開業資金の目安

### 業態別の初期費用

| 業態 | 初期費用の目安 |
|------|--------------|
| 屋台・テイクアウト専門 | 100〜300万円 |
| 小さなカウンター寿司（8席以下） | 500〜1,000万円 |
| 中規模の回転なし寿司店（15〜20席） | 1,000〜2,000万円 |
| 高級おまかせ店（完全予約制・6席） | 800〜1,500万円 |

### 資金の内訳（カウンター寿司・10席の場合）

| 項目 | 費用 |
|------|------|
| 物件取得費（敷金・礼金） | 100〜200万円 |
| 内装・改装費 | 200〜400万円 |
| 厨房設備（冷蔵ケース・ネタケース等） | 100〜200万円 |
| 道具・食器・消耗品 | 30〜80万円 |
| 運転資金（開業3ヶ月分） | 100〜200万円 |
| **合計** | **530〜1,080万円** |

---

## 資金調達方法

### 日本政策金融公庫の創業融資（最優先）

飲食業の創業融資では最もメジャーな方法です。

- 金利：1.6〜2.7%（2024年時点）
- 融資額：最大7,200万円（新創業融資制度）
- 自己資金の要件：創業資金の10分の1以上

**事業計画書が重要：** 売上予測・原価率・人件費・家賃を細かく作ると融資が通りやすくなります。

### 補助金・助成金

- **小規模事業者持続化補助金**：販促費・設備費を最大50万円補助
- **創業補助金**：地域によって上限100〜200万円
- 商工会議所に相談すると申請をサポートしてくれます

## 物件選びのポイント

### 立地の条件

| 優先度 | 項目 |
|--------|------|
| 高 | 駅から徒歩5分以内（ランチ需要がある場合） |
| 高 | 目的型の場合は駅距離より「住宅街・オフィス近く」が重要 |
| 中 | 1階路面店か2〜3階か（2階以上は家賃が安いが集客が難しい） |
| 低 | 有名店の近く（競合になる場合あり） |

### 居抜き物件を狙え

厨房設備が残っている「居抜き物件」なら内装費を大幅に削減できます。
飲食業の廃業物件情報は「居抜き情報サイト（TENPOS・店舗流通ネット）」で確認できます。

## 食材仕入れ先の選び方

### 仕入れルートの種類

| ルート | メリット | デメリット |
|--------|---------|-----------|
| 豊洲・地方市場 | 新鮮・種類豊富・安い | 早朝（4〜5時）に行く必要がある |
| 業務用仕入れ業者（魚屋・水産業者） | 配達してくれる・安定供給 | 市場より割高 |
| 宅配水産（フーコ・かねます等） | 産地から直送 | 送料がかかる |

**最初は業者を2〜3社試して、品質・価格・対応を比較するのがおすすめ。**

## 開業前の許認可・手続き一覧

| 手続き | 提出先 | 期限 |
|--------|--------|------|
| 食品営業許可 | 保健所 | 開業前 |
| 食品衛生責任者の設置 | 保健所への届出 | 開業前 |
| 個人事業主の開業届 | 税務署 | 開業から1ヶ月以内 |
| 青色申告承認申請 | 税務署 | 開業から2ヶ月以内 |
| 深夜に酒類提供する場合 | 警察署 | 開業前 |
| 法人の場合：法人設立登記 | 法務局 | 開業前 |

## 集客ゼロからのスタート戦略

### 開業前の情報発信（3ヶ月前から）

1. Instagramアカウントを作成し、物件探し・内装工事・仕込みの様子を投稿
2. Googleマイビジネスを登録（開業前から予告投稿ができる）
3. 食べログ・Retty・ホットペッパーにページを作成

### 開業直後の集客

- **グランドオープン特典**（最初の2週間は10%オフ等）
- **地域へのチラシポスティング**（飲食店には意外と効果あり）
- **SNSでのプレゼント企画**（フォロー＆リポストで招待券プレゼント）
