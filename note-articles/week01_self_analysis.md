# 【Week1】寿司職人転職の自己分析シート：あなたに向いているルートはどれ？

「寿司職人になりたい」という気持ちはあるけど、何から始めればいいかわからない。
スクール？修行？独立？調べるほど情報が多すぎて混乱する。

そのもやもやを解消するのが、この Week1 のミッションです。

転職を成功させた人と失敗した人の一番の違いは**「自分のルートを決めるまでの速さ」**でした。

---

## ルート診断：あなたに合うのはどれ？

まず以下の質問に答えてみてください。

### Q1. 転職後、最初に就職したいですか？それとも最初から独立？

- A) まずどこかの寿司店に就職したい → **スクール or 修行ルート**
- B) 最初から自分でやりたい（出張寿司・独立） → **スクール→即独立ルート**

### Q2. 時間はどれくらいかけられますか？

- A) 1〜3ヶ月で技術習得したい → **スクールルート**
- B) 3〜5年かけてじっくり本物の技術を身につけたい → **修行ルート**
- C) 副業から始めてリスクなく転職したい → **副業スタートルート**

### Q3. 海外で働くことに興味がありますか？

- A) いつか海外で働いてみたい → **寿司アカデミー（海外対応スクール）が最有力**
- B) 国内でキャリアを積みたい → **飲食人大学など国内特化スクール**

---

## 3つのルートの特徴まとめ

### ルート① スクール（最短・現代のスタンダード）

| 項目 | 内容 |
|------|------|
| 期間 | 1〜6ヶ月 |
| 費用 | 30〜100万円（給付金で最大70%オフ可） |
| 就職先 | 高級寿司店・回転寿司・ホテル・海外 |
| 向いている人 | 20〜40代・時間と効率重視・社会人 |

**メリット：** 短期で技術習得、就職サポートあり、給付金が使える
**デメリット：** 費用がかかる、一流店への就職は難しい場合も

---

### ルート② 弟子入り・修行（伝統的なルート）

| 項目 | 内容 |
|------|------|
| 期間 | 3〜10年 |
| 費用 | ほぼゼロ（給与をもらいながら）|
| 就職先 | 修行先の紹介・のれん分け |
| 向いている人 | 10〜20代・高級店の職人を目指す人 |

**メリット：** 費用がかからない、深い技術が身につく
**デメリット：** 時間がかかる、師匠との相性次第、待遇が悪い場合も

---

### ルート③ 副業スタート→独立

| 項目 | 内容 |
|------|------|
| 期間 | 副業開始まで3ヶ月、本業転換まで1〜2年 |
| 費用 | スクール30〜80万円＋道具代30〜50万円 |
| 収入 | 副業月5〜20万円→独立後月50〜100万円 |
| 向いている人 | リスクを取りたくない・現職を続けながら試したい |

**メリット：** 失敗リスクが最小、自分のペースで進められる
**デメリット：** 時間がかかる、二足のわらじの大変さ

---

## 自己分析ワーク：3つの質問に答えてみよう

転職前に紙に書き出してください（5分でOK）。

**① なぜ今の仕事をやめたいのか（本音で）**

> 例：「給料が低い」「つまらない」「体を動かす仕事がしたい」「接客が好き」

**② 寿司職人になって、5年後にどうなっていたいか**

> 例：「高級店で板長になりたい」「海外で自分の店を持ちたい」「副業で月10万稼ぎたい」

**③ 転職に使える時間とお金はどれくらいか**

> 例：「貯金100万・3ヶ月間は転職活動に集中できる」

この3つが明確になれば、自然とルートが決まります。

## まとめ

| タイプ | おすすめルート |
|--------|--------------|
| とにかく早く転職したい | スクール→就職 |
| 本物の技術・高級店志向 | 修行（20代限定） |
| リスクゼロで確かめたい | 副業スタート |
