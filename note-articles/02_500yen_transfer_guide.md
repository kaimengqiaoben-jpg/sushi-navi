## 1. スクールは「基準」で比較する

特定のスクールをおすすめするのではなく、比較するときに見るべき基準を整理します。個々のスクールの実際の評判・実績は、必ず自分で見学・問い合わせて確認してください（後述のチェックリスト参照）。

| 比較軸 | 確認すること |
|---|---|
| 目的との一致 | 高級店志向／海外志向／和食全般／資格取得、どれを軸にしたコースか |
| 期間と費用 | 短期（1〜3ヶ月・30〜80万円）〜長期（1〜2年・100万円超）まで幅がある |
| 就職支援の中身 | 紹介だけか、面接対策・履歴書添削まで見るか。具体的な就職先を教えてもらえるか |
| 実技の比率 | 座学より実技時間の比率。最低6割以上が目安 |
| 海外対応 | 海外就職を考えるなら、英語対応コース・海外求人の実績があるか |

「〇〇なら唯一の選択肢」というような断定は、実際には見学・比較してみないとわかりません。複数校を必ず比較してください。

## 2. 費用を抑える給付金の使い方

スクールを選ぶ前に、給付金制度を確認してください。対象スクールなら費用を抑えられます。

### 専門実践教育訓練給付金

- **補助率：** 受講費用の最大70%
- **対象：** 雇用保険加入者（会社員・元会社員）
- **手続き先：** ハローワーク
- **条件：** 厚労大臣が指定したスクール・コースのみ対象

### 一般教育訓練給付金

- **補助率：** 受講費用の20%（上限10万円）
- **対象：** 雇用保険加入期間1年以上（初回は6ヶ月以上）
- **手続き先：** ハローワーク

### 手続きの流れ

1. ハローワークに行って「教育訓練給付金の相談をしたい」と伝える
2. 自分が対象かどうか確認してもらう
3. 対象スクールの中から選ぶ
4. **受講開始前に**申請が必要な制度もあるので、入学を決める前に必ず確認する
5. 受講終了後に申請→給付金が振り込まれる

制度の給付率・対象条件は改定されることがあるため、必ず最新の公式情報（厚生労働省・ハローワーク）で確認してください。

## 3. 30代・未経験からの転職で意識したいこと

年齢を理由に諦める必要はありません。よく見られるパターンを3つ紹介します（特定の個人の体験談ではなく、一般的な傾向です）。

### パターン①：スクール→未経験歓迎の店→高級店

最も現実的なルートです。

1. スクール（1〜3ヶ月）で基礎技術習得
2. 未経験歓迎の店（回転寿司チェーンや寿司居酒屋など）に就職
3. 1〜2年働いて技術・スピードを鍛える
4. 高級店や独立へステップアップ

前職が接客業だった場合、社会人としてのコミュニケーション力が早い段階で評価されるケースがよく見られます。

### パターン②：スクール→即独立（出張寿司）

店舗を持たず出張寿司から始める、リスクの低い独立方法です。

1. スクール（1〜3ヶ月）で基礎技術習得
2. 道具を揃えて出張寿司として活動開始（初期費用20〜50万円）
3. SNSなどで集客して実績を積む
4. 軌道に乗ったら実店舗へ

前職がIT・マーケティング系だった場合、SNS運用や予約の仕組みづくりが強みになりやすい領域です。

### パターン③：副業→転職

すぐに転職せず、まず副業として始めて確認してから転職する堅実なパターンです。

1. 週末にスクールの短期講座（体験コース）で技術チェック
2. 出張寿司・ケータリングで副業スタート
3. 収入が安定したら本業として転職・独立

## 4. 失敗しないスクール選びチェックリスト

スクール見学・問い合わせ時に必ず確認してください。

**費用について**
- [ ] 給付金制度は使えるか？
- [ ] 教材費・道具代は授業料に含まれているか？
- [ ] 分割払い・教育ローンは使えるか？

**就職について**
- [ ] 就職先の具体的な実績（業態・地域）を教えてもらえるか？
- [ ] 就職サポートの期間はいつまでか？
- [ ] 卒業生の進路を具体的に聞けるか？

**カリキュラムについて**
- [ ] 実技の時間は全体の何%か？（最低60%以上が理想）
- [ ] シャリの握り方・魚のさばき方は授業に含まれているか？
- [ ] 衛生管理・食品の知識も教えてもらえるか？

**スクール自体について**
- [ ] 見学・体験入学はできるか？
- [ ] 在校生・卒業生に話を聞けるか？
- [ ] 講師は現役または元プロの寿司職人か？
