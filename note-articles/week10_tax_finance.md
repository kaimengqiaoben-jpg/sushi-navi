# 【Week10】寿司職人・フリーランス料理人のお金管理【節税・確定申告】

副業で稼ぎ始めた。独立して売上が出てきた。
でも税金のことを理解していないと、稼いだお金がごっそり持っていかれます。

「難しいから後で考える」は一番危険。今回は料理人が最低限知っておくべきことをシンプルに整理します。

## フリーランス料理人が使える経費一覧

自分のビジネスのための支出は「経費」として売上から引けます。
経費が増えるほど「課税される所得」が減り、税金が安くなります。

### 出張寿司・独立店で経費になるもの

| カテゴリ | 具体的な例 |
|---------|-----------|
| 食材費 | 魚・米・醤油・わさび等の仕入れ費用 |
| 道具・消耗品 | 包丁・まな板・手袋・アルコール |
| 交通費 | お客様宅への移動費（電車・タクシー） |
| 通信費 | スマホ代・インターネット代（仕事用割合分） |
| 広告宣伝費 | Instagram広告・チラシ印刷代 |
| 研修・学習費 | スクール受講料・料理本・セミナー参加費 |
| 白衣・ユニフォーム | 仕事用の服・エプロン |
| 家賃（按分） | 自宅で作業している場合の一部 |
| 保険料 | 損害賠償保険（食中毒保険等） |

**レシート・領収書は必ず保管。捨てると経費として認められません。**

## 確定申告の流れ

### 対象になる人

- 副業の年間所得が20万円超の会社員
- フリーランス・独立した個人事業主すべて

### 白色申告 vs 青色申告

| 種類 | メリット | デメリット |
|------|---------|-----------|
| 白色申告 | 簡単 | 節税メリットが少ない |
| **青色申告（推奨）** | 最大65万円控除・赤字繰越3年 | 帳簿が必要（ソフトで簡単） |

**絶対に青色申告にするべきです。** 開業届と一緒に「青色申告承認申請書」を税務署に出すだけです。

### 申告スケジュール

| 時期 | やること |
|------|---------|
| 毎月 | 売上・経費をレシートとともに記録（freee・マネーフォワード等） |
| 1〜2月 | 年間の収支をまとめる |
| 2/16〜3/15 | 確定申告書を税務署に提出 |

---

## 消費税とインボイス登録の判断

### 原則

年間売上1,000万円未満なら消費税の納税は不要（免税事業者）。

### インボイス登録すべきか？

| 状況 | 判断 |
|------|------|
| 個人のお客様だけを対象（出張寿司・一般客向け） | **登録しなくてOK** |
| 法人・会社が顧客（法人向けケータリング・仕入れ業者） | **登録を検討** |

一般消費者向けの出張寿司がメインなら、当面は登録しなくて問題ありません。

## 老後の備え（個人型確定拠出年金・iDeCo）

フリーランスには会社員の退職金や厚生年金がありません。
**iDeCo（イデコ）** で老後資金を積み立てれば、その掛け金が全額所得控除になります。

| 項目 | 内容 |
|------|------|
| 月の掛け金上限 | 個人事業主は月6.8万円（会社員は1.2万円） |
| 節税効果 | 年間掛け金×所得税率分が戻ってくる |
| 例 | 月3万円積立＋税率20%の場合→年7.2万円節税 |

副業で月10万円稼いでいる人が月3万円iDeCoに積み立てると、老後の備えを作りながら年7万円以上の節税になります。

## 税理士に頼むべきタイミング

| 年商 | 判断 |
|------|------|
| 〜300万円 | freee・マネーフォワードで自力OK |
| 300〜1,000万円 | 確定申告時期だけ税理士に相談（スポット依頼で3〜5万円） |
| 1,000万円〜 | 顧問税理士を付ける（月2〜5万円）メリットが大きい |
