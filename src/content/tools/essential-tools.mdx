このページは、寿司職人が実際に使う道具を一覧にした「道具カテゴリーの入口」です。個々の道具の詳しい選び方は、それぞれの記事にリンクしています。

寿司の道具は「これがないと仕事にならない」ものと「あると速い・きれいになる」ものに分かれます。以下では前者を中心に、板場に立つ順で並べています。

## 包丁

| 包丁 | 用途 | 優先度 |
|---|---|---|
| 柳刃包丁 | 刺身・握りのネタを引く | 最優先 |
| 出刃包丁（または船行包丁） | 魚をおろす、頭を落とす | 高 |
| 薄刃包丁 | 野菜、かつらむき、つま・けん | 中 |
| 小出刃 | 小魚を数多くさばく | 現場による |
| ペティ / 牛刀 | 細かい作業、薄刃の代用 | あると便利 |

## 砥石（研ぎの道具）

包丁と同じだけ重要なのが砥石です。切れない包丁はネタの断面を潰し、仕上がりを落とします。

| 種類 | 番手の目安 | 役割 |
|---|---|---|
| 荒砥 | 〜#400 | 刃が欠けたときの修正 |
| 中砥 | #800〜#2000 | 日常の研ぎの主役 |
| 仕上げ砥 | #3000〜#8000 | 切れ味と刃先の仕上げ |
| 面直し砥 | — | 砥石の面を平らに保つ（必須） |

砥石はセラミック系を使用しています。詳しくは[砥石のおすすめ](/tools/whetstone-osusume/)。

## 調理の小物

- **飯台（はんだい）／シャリ切り用のしゃもじ**：シャリを切る・冷ます
- **まきす**：巻物、棒寿司、昆布締めの成形
- **玉子焼き器（関東型の角鍋）**：厚焼き玉子
- **バット・ボウル**：仕込みの下ごしらえ、ネタの保管
- **骨抜き・毛抜き**：小骨の処理。先の合いがいいものを選ぶ
- **ピンセット**：あしらいの盛り付け
- **刷毛（はけ）**：煮切りを塗る
- **ふきん・さらし**：ネタを扱う手前、水気の管理。枚数が要る

## 着るもの・履くもの

| 品 | 選ぶ基準 |
|---|---|
| 白衣 / 作務衣 | 洗濯頻度に耐える生地、乾きやすさ、動きやすさ |
| 前掛け | 防水性、結び直しのしやすさ |
| コックシューズ / 長靴 | 厨房で滑らない、長時間立っても疲れにくい |
| 帽子 / バンダナ | 毛髪対策（衛生の必須要件） |

詳しくは[作務衣・白衣・履物の選び方](/tools/samue-uniform/)。

## 持ち運び・保管

- **包丁ケース（差し・巻き）**：包丁を3本持つ時点で必要
- **サヤ（鞘）**：1本ずつの保護
- **道具箱**：出張・移動のある働き方なら

## このカテゴリーの読み方

道具は「まず包丁と砥石」。この2つの選び方と手入れができれば、残りは仕事をしながら必要に応じて足していけます。各記事は、実際に使っているものの写真と使用期間を添えて、メリットだけでなく「向かない人」も書くようにしています（[編集方針](/editorial-policy/)）。
