寿司職人の1日は「営業時間」だけではありません。その前後の仕込みと片付けが仕事の大部分を占めます。ステージ別に流れを見ていきます。

## 修行中（1〜3年目）の1日

| 時間 | 内容 |
|---|---|
| 8:00 | 出勤・掃除。先輩より早く入るのが基本 |
| 9:00〜12:00 | 仕込みの補助。魚の下処理、野菜のカット、シャリの準備。最初のうちは見て覚える時間が多い |
| 12:00〜14:00 | ランチ営業。補助・配膳・洗い物。握りは触らせてもらえないことも |
| 14:00〜17:00 | 休憩・自主練。この時間に握りやかつらむきの練習をする人が多い |
| 17:00〜22:00 | ディナー営業。先輩の動きを見ながら補助 |
| 22:00〜23:00 | 片付け・翌日の準備確認・退勤 |

労働時間は12〜14時間になることもあります。給料の目安は[給料の記事](/career/salary/)を参照。

## 付け場担当（一人前）の1日

| 時間 | 内容 |
|---|---|
| 9:00 | 出勤・仕込み開始。自分でネタの状態を見ながら組み立てる |
| 11:00〜14:00 | ランチ営業。カウンターで握る。会話しながら客の好みを引き出す |
| 14:00〜17:00 | 休憩・仕込みの続き。後輩の指導もこの時間 |
| 17:00〜22:00 | ディナー営業。おまかせの流れをコントロールする |
| 22:00〜23:00 | 片付け・翌日準備。段取りが良くなり労働時間は10〜12時間程度に |

## 独立後（店主）の1日

| 時間 | 内容 |
|---|---|
| 8:00 | 市場・仕入れ。自分で魚を選ぶ。ここで店の味が決まる |
| 10:00〜12:00 | 仕込み・スタッフへの指示・コース内容の確認 |
| 12:00〜22:00 | 営業（ランチ＋ディナー）。接客・調理・経営を並行 |
| 22:00〜24:00 | 片付け・売上計算・発注・予約管理・SNS更新 |

体力的にはハードですが、仕入れから提供まで自分の判断で回せる面白さがあります。

## やりがいときつさ

**やりがい**

- 目の前で客の反応が見られる
- 技術が上達する手応えがある
- 季節の食材を扱える
- 海外でも通用する技術が身につく

**きついところ**

- 修行中は長時間労働で賃金が低い
- 立ち仕事で体に負担がかかる
- 冷蔵庫と熱い厨房を行き来する
- 土日祝が繁忙で休みが取りにくい
- 古い職場だと体育会系の文化が残っていることがある

## 向いている人

- 地道な反復練習を続けられる
- 手先の作業に苦がない（または上達したいと思える）
- 人を喜ばせることに満足を感じる
- 食べること・食材そのものへの興味が強い
